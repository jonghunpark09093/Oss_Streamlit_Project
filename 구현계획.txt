3. 필수 기능 구현 방법
----------------------------------------------

[첫 화면 - 학번/이름]
  로그인 화면의 중앙 컬럼 최상단에 배너로 항상 표시
  로그인 이후 화면(소개/퀴즈/결과)에서는 배너 제거

[로그인 기능]
  - 미리 정의된 USERS dict와 입력값 비교
  - st.form + st.text_input(type="password") 사용
  - 성공: st.session_state.logged_in = True 후 intro 페이지로 이동
  - 실패: st.error() 오류 메시지 출력
  - 비밀번호 복잡도 충족 (대소문자+숫자+특수문자) → 브라우저 유출 경고 방지

[캐싱 기능]
  @st.cache_data 데코레이터 적용 대상 (총 3개 함수):

  1) load_questions(): questions.json 로딩
  2) load_teams():     teams.json 로딩
  3) load_image_base64(): 선수 이미지 파일을 base64로 인코딩

  캐싱 이유:
    Streamlit은 사용자 인터랙션(버튼 클릭, 라디오 선택 등)마다
    전체 스크립트를 재실행한다. @st.cache_data 없이는 매 렌더링마다
    파일 I/O가 반복 발생한다.
    특히 이미지 base64 인코딩은 비용이 크므로 캐싱 효과가 명확하다.

[퀴즈 기능 - 점수 계산 방식]
  - session_state.answers: {문항번호: 선택텍스트} 로 답변 저장
  - Streamlit 위젯 key는 미렌더링 시 자동 소멸하므로
    별도 answers dict에 수동 저장하는 방식 채택
  - 마지막 문항 완료 시 _calc_scores()가 answers 전체를 순회하여
    팀별 점수를 한 번에 계산 → session_state.scores에 저장
  - 보기별 점수 구조: {"팀코드": 점수, ...}
    (2점: 핵심 정체성 일치, 1점: 부분 연관)

[뒤로가기 기능]
  - 이전 버튼 클릭 시 current_q -= 1 후 st.rerun()
  - 라디오 index 파라미터에 answers.get(idx)로 이전 선택 복원
  - 뒤로가서 답 변경 가능, 결과도 변경된 답 기준으로 재계산

[동점 처리]
  - max(scores.values())로 최고 점수 산출
  - 동점 팀 전체를 top_keys 리스트로 추출
  - is_tie 플래그로 단독/동점 케이스 분기
  - 동점 시 경고 배너 + 팀 카드 여러 개 순서대로 표시

4. 8개 팀 선정 근거 및 점수 산정 기준
----------------------------------------------

[팀 선정 원칙]
  NFL 32팀 중 아래 기준으로 8팀 선발:
  - 팀 정체성이 뚜렷하고 서로 겹치지 않을 것
  - AFC/NFC, 대도시/소도시, 선벨트/혹한 지역 등 다양성 확보
  - NFL 비팬도 이름을 알 수 있는 브랜드 인지도

[팀별 선정 근거]

  Kansas City Chiefs (KC)
    근거: 최근 5년 슈퍼볼 4회 진출. Andy Reid 감독은 NFL 역대
    최고 전략가 중 하나로 평가. Mahomes의 정밀 패싱이 핵심.
    테마: 전략적, 승리지향, 패싱 오펜스

  San Francisco 49ers (SF)
    근거: 2023 시즌 런패스 균형 지표(DVOA) 상위권.
    Shanahan 시스템은 팀워크와 포지션 순환이 핵심.
    테마: 균형, 팀워크, 시스템 중심

  Dallas Cowboys (DAL)
    근거: Forbes 기준 NFL 최고 가치 팀($9.2B, 2023).
    "America's Team" 별명, AT&T 스타디움은 NFL 최대 규모.
    테마: 화려함, 엔터테인먼트, 대도시

  Green Bay Packers (GB)
    근거: NFL 유일 팬 소유 비영리 구단.
    인구 10만의 소도시에서 NFL 최고 팬 충성도 보유.
    Favre→Rodgers로 이어지는 레전드 QB 계보.
    테마: 전통, 팬 유대감, 클래식

  Pittsburgh Steelers (PIT)
    근거: NFL 최다 타이 슈퍼볼 우승(6회).
    Steel Curtain 수비 유산, 강력한 런+수비 정체성 유지.
    테마: 강인함, 수비, 공업 도시

  Miami Dolphins (MIA)
    근거: 2023년 NFL 최다 득점 오펜스.
    따뜻한 기후와 South Beach 문화, 스피드 중심 플레이.
    테마: 스피드, 화려함, 선벨트

  Buffalo Bills (BUF)
    근거: ESPN 팬 충성도 지수 최상위권.
    Bills Mafia 문화, 버팔로 혹한 홈 어드밴티지 유명.
    테마: 팬 열정, 악천후, 소도시 근성

  Las Vegas Raiders (LV)
    근거: NFL에서 가장 독특한 팀 문화(검정+은 컬러, Black Hole 팬섹션).
    라스베이거스 Allegiant Stadium은 NFL 최신 실내 경기장.
    테마: 반항적, 독특함, 화려한 도시

[점수 2점 vs 1점 기준]
  2점: 해당 특성이 팀의 핵심 정체성
       → 그 팀을 설명할 때 가장 먼저 언급되는 특징
  1점: 해당 특성과 연관성이 있으나 부차적
       → 공유하지만 대표 이미지는 아님

  예시:
  - KC + "전략적이고 냉철" = 2점
    (Andy Reid의 전략, Mahomes의 정밀함 = 팀의 핵심)
  - KC + "공격적이고 승부욕 강함" = 1점
    (공격적이긴 하나 이미지는 "폭발력"보다 "정교함")
  - PIT + "강력한 런닝 게임" = 2점
    (Steel Curtain 이후 수십 년간 팀 정체성의 핵심)
  - DAL + "대도시 선호" = 2점
    (NFL 최고가치팀, 엔터테인먼트 문화의 상징)
  - GB + "팬과의 유대감" = 2점
    (팬이 구단주인 유일한 팀, 팬 = 팀 자체)
