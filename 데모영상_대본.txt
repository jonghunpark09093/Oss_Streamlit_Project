[00:00 ~ 00:30] 자기소개 및 주제 소개
----------------------------------------------

  안녕하세요. 학번 2021204039, 박종훈입니다.

  이번 오픈소스소프트웨어실습 중간고사 대체 과제로 Streamlit을 활용한
  "나에게 맞는 NFL 팀 추천 테스트" 앱을 제작했습니다.

  10가지 성향과 취향 질문에 답하면, 미국 프로풋볼 리그인 NFL의
  32개 팀 중 엄선한 8개 팀 가운데 나와 가장 잘 맞는 팀을
  추천해주는 앱입니다.

  앱에는 과제 필수 기능인 로그인, 캐싱, 퀴즈 기능이
  모두 구현되어 있습니다. 지금부터 시연 시작하겠습니다.

----------------------------------------------
[00:30 ~ 01:20] 첫 화면 & 로그인 기능 시연
----------------------------------------------

  [화면: 터미널에서 streamlit run app.py 실행 후 브라우저 오픈]

  앱을 실행하면 가장 먼저 이 로그인 화면이 나타납니다.

  먼저 로그인 실패 케이스를 보여드리겠습니다.
  [아이디: admin, 비밀번호: 틀린값 입력 → 로그인 클릭]

  보시는 것처럼 "아이디 또는 비밀번호가 올바르지 않습니다"라는
  오류 메시지가 출력됩니다.

  로그인 기능은 코드에 미리 정의된 사용자 계정 정보와
  입력값을 비교하는 방식으로 구현했습니다.
  로그인 성공 여부는 session_state의 logged_in 변수로 관리하여,
  로그인 전에는 다음 화면에 접근할 수 없습니다.

  이제 올바른 정보로 로그인합니다.
  [아이디: admin, 비밀번호: Nfl2025! 입력 → 로그인 클릭]

  로그인에 성공하면 테스트 소개 화면으로 이동합니다.
----------------------------------------------
[01:20 ~ 02:10] 캐싱 기능 설명
----------------------------------------------

  [화면: 테스트 소개 화면]

  이 화면에서 캐싱 기능에 대해 설명하겠습니다.
  Streamlit은 사용자 인터랙션(버튼 클릭, 라디오 선택 등)마다
  전체 스크립트를 재실행합니다. @st.cache_data 없이는 매 렌더링마다
  파일 I/O가 반복 발생합니다

  이 앱에서는 다음 세 함수에 @st.cache_data를 적용했습니다.
  첫째, questions.json 파일을 읽는 load_questions 함수.
  둘째, teams.json 파일을 읽는 load_teams 함수.
  셋째, 선수 이미지를 base64로 인코딩하는
        load_image_base64 함수입니다.

  @st.cache_data가 붙은 함수는 최초 1회만 실행되고,
  이후 동일한 인자로 호출되면 저장된 결과를 즉시 반환합니다.
  [화면: 테스트 시작 버튼 클릭]

  테스트를 시작합니다.

----------------------------------------------
[02:10 ~ 03:30] 퀴즈 풀이 시연
----------------------------------------------

  [화면: 퀴즈 Q1 화면]

  총 10문항의 객관식 퀴즈가 시작됩니다.
  상단의 프로그레스 바로 현재 진행 상황을 확인할 수 있습니다.

  퀴즈 데이터는 questions.json 파일에 저장되어 있으며,
  각 보기에는 NFL 팀별 점수가 연결되어 있습니다.
  예를 들어 "전략적이고 냉철하게 판단한다"를 선택하면
  Kansas City Chiefs에 2점, 49ers에 2점이 부여됩니다.

  [보기 선택 후 다음 클릭, Q2, Q3 빠르게 진행]

  이제 뒤로가기 기능을 시연합니다.
  [이전 버튼 클릭 → Q2로 돌아감]

  이전 버튼을 누르면 직전 문항으로 돌아갑니다.
  이때 이전에 선택했던 보기가 그대로 유지되는 것을 확인할 수 있습니다.

  이 기능은 session_state.answers 딕셔너리에
  문항 번호를 키로, 선택한 텍스트를 값으로 저장하는 방식으로
  구현했습니다.
  Streamlit의 위젯 key 값은 해당 위젯이 화면에 렌더링되지 않으면
  자동으로 삭제되는 특성이 있기 때문에, 별도 딕셔너리에
  수동으로 저장하는 방식을 택했습니다.

  [보기 선택 후 나머지 문항 빠르게 완료]

  [마지막 문항에서 "결과 보기" 버튼 클릭]

  마지막 문항에서는 "다음" 대신 "결과 보기" 버튼이 표시됩니다.
  이 버튼을 클릭하는 순간 _calc_scores 함수가 실행되어
  answers 딕셔너리 전체를 순회하며 팀별 점수를 합산합니다.

----------------------------------------------
[03:30 ~ 04:20] 결과 화면 시연
----------------------------------------------

  [화면: 결과 화면]

  결과 화면에서 나에게 추천된 NFL 팀이 카드 형태로 표시됩니다.
  팀 고유 컬러의 테두리와 배경, 팀 소개 및 추천 이유가 함께 나옵니다.

  하단의 "전체 팀 점수 보기"를 클릭하면
  8개 팀의 점수 순위를 전부 확인할 수 있습니다.
  이는 텍스트를 활용해 만든 막대그래프입니다.

  보시는 것처럼 두 팀이 동점일 경우
  몇 개 팀이 동점인지 안내 메시지와 함께
  해당 팀 카드가 모두 표시됩니다.
  한 팀만 선정될 경우 한 팀만 표기됩니다.

  동점 처리는 scores 딕셔너리에서 최고 점수를 구한 뒤,
  동일 점수를 가진 팀을 리스트로 추출해
  카드를 반복 렌더링하는 방식으로 구현했습니다.

  그리고 expander를 활용해 팀 선정 기준에 대한 설명도 추가했습니다.
